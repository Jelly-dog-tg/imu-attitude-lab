# 硬件连接记录

以下连接按当前项目记录整理；上电前务必对照你实际使用的开发板、传感器模块引脚标识再检查一次。

## STM32F103C8T6 ↔ MPU9250（I2C1）

| STM32 | MPU9250 模块 | 说明 |
|---|---|---|
| PB6 | SCL | I2C1 时钟 |
| PB7 | SDA | I2C1 数据 |
| GND | GND | 共地 |
| 电源 | 模块电源输入 | 严格按模块标注确认电压；不要默认所有模块都可直接接 5 V |

当前代码使用 MPU9250 的 7-bit 地址 `0x68`（I2C API 中发送时左移一位）。若 AD0 接法不同，实际地址可能不同。

## STM32F103C8T6 ↔ CH340（USART1）

| CH340 | STM32 | 说明 |
|---|---|---|
| TXD | PA10 / USART1_RX | 交叉连接 |
| RXD | PA9 / USART1_TX | 交叉连接 |
| GND | GND | 共地 |

固件当前配置 `9600, 8-N-1`。使用串口工具时应选相同参数，并关闭会占用同一 COM 口的其他程序。

## ST-Link

ST-Link 用于下载与调试，SWDIO、SWCLK、GND 连接应根据开发板引脚标识确认。不要把 ST-Link 和 CH340 的 TX/RX 引脚混接。
